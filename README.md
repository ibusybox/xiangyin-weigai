# 乡音未改｜Unchanged Hometown Voice

## 鬓毛虽白 乡音未改
本项目是开源共建的汉语方言口述档案，面向客家话、潮汕话、闽南话、吴语、湘语等各地方言，收集老一辈长者的原生口述录音，收录童谣、俗谚、民间故事与日常闲谈。  趁长者的声音尚在，抢救留存口头语言，不让这些世代口传的乡音，随一代人逝去而永久消散。 


## 贡献说明

欢迎各地志愿者参与：回乡寻访长辈录音、整理方言转写、校对词汇注释、维护档案索引。
原始音频不存入 Git 仓库，GitHub 仅存放元数据索引、采集规范、处理脚本，音频档案归档至 ScienceDB/Zenodo 长期保存。

## 伦理准则

1. 所有录音**必须取得受访者知情同意**，受访者可随时申请撤回并删除录音；
2. 保护隐私，记录使用代号，不强制采集姓名、住址等敏感信息；
3. 全部资料仅限非商业的方言保护与学术研究，禁止商用。
